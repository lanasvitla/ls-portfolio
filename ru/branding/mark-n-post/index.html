Mark’n’Post / лендинг для логистической компании

Лендинг для сервиса доставки из Грузии в Европу и страны СНГ: услуги, маршруты, процесс отправки, сбор заявок через Telegram, блок с реальными отзывами и рейтингом.

Web design Landing Page Vibe coding

Задача

Собрать понятный лендинг для логистического сервиса: показать форматы отправки, объяснить процесс, усилить доверие через проверяемые источники и привести пользователя к заявке в Telegram.

Моя роль

Структура лендинга, UX/UI, исследование и визуальная система страницы, вайб кодинг (Claude Code / GitHub Pages), Telegram-сценарий заявки.
